<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">「钱多、事少、离家近」，曾经是很多人对「好工作」最朴素的想象。年轻时衡量一份工作，我们最常问的也是：这份工作现在能给我多少？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">但过了35岁以后，我越来越觉得，单单问「能给我多少」已经不够了，还应该多问一句：「按现在这种工作方式，我还能持续多久？」</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">如果把时间拉长来看，更值得思考的是：这份工作，是在增加我未来的选择权，还是在一点一点消耗它？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">所以现在重新判断一份工作值不值得继续，我不会只看工资和Title，而会换一套算法。</p>
<table width="100%" cellpadding="0" cellspacing="0" style="margin:36px 0 16px 0;"><tr><td width="4" style="background-color:#5BA88E;"></td><td style="background-color:#EBF7F3;padding:13px 18px;"><strong style="font-size:16px;color:#1A3D36;letter-spacing:1.5px;">一、为什么35岁以后，要换一套算法</strong></td></tr></table>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这套以工资、职位和平台为核心的算法，在职业生涯早期并没有错。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">一个人的学历、经验和创造的价值，本就应该在市场上得到相应的回报。收入不是一个需要避讳的指标。问题在于，当职业生涯越来越长，只用这一套指标来判断，已经不够了。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">2026年5月，《哈佛商业评论》发表了一篇关于职业生涯延长与40多岁职场人的文章，把这个阶段称为 <strong style="color:#1A3D36;">Pivotal 40s——关键的40岁</strong>。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">文章指出，随着人的工作年限不断拉长，一个人的职业生涯很可能延续到70多岁甚至更久。也就是说，对一个40岁左右的人来说，前面很可能还有二三十年的职业人生，远没有到「终点在望」的时候。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">可恰恰到了这个阶段，工作上的责任更重了，家庭里的负担更多了，时间也被挤得越来越紧。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">20多岁的时候，人还有比较多的空间去尝试；到了五六十岁，很多人已经开始重新思考人生的下一站。但夹在中间的40多岁，却往往既身负重任，又很少有机会真正停下来——<strong style="color:#1A3D36;">这一群人最需要反思，也最没有时间反思。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这并不是说，35岁以后就应该降低野心。恰恰相反，前面的路还很长，职业规划更需要从一次次追求眼前的「更高」，转向考虑一条路能不能长期走下去。</p>
<p style="font-size:16px;color:#1A3D36;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;font-weight:bold;text-align:justify;">真正要改变的，是衡量职业发展的时间尺度。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">如果职业生涯还有很长一段路要走，许多今天看起来很划算的选择，就值得放到更长的时间里重新算一遍。</p>
<table width="100%" cellpadding="0" cellspacing="0" style="margin:36px 0 16px 0;"><tr><td width="4" style="background-color:#5BA88E;"></td><td style="background-color:#EBF7F3;padding:13px 18px;"><strong style="font-size:16px;color:#1A3D36;letter-spacing:1.5px;">二、真正要算的，是这六本账</strong></td></tr></table>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">香港还是新加坡？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">加拿大还是美国？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">留在原来的市场，还是跟着新的产业机会去另一个国家？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">今天讨论职业选择，尤其是有国际背景的职场人，很容易遇到这样的「灵魂拷问」时刻。我们会比较工资、税率、职位数量、公司平台等等，做一轮又一轮的评估。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">工资更高、平台更大、职位再往上一层，常常会被我们视为一次「职业升级」。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">但假如一个选择可以让你的收入提高30%，与此同时，你的工作节奏明显加快，自由支配时间大幅减少，身体恢复的成本也越来越高——</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这究竟算不算一次真正的职业升级？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我们不妨先把一份工作的价值拆开来看。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第一本，收入账。</strong> 它给我的现实回报是否合理？除了支撑现在的生活，能不能也给我应对未来的变化留一点余地？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第二本，时间与精力账。</strong> 一天工作结束以后，我还剩多少时间和精力，可以用来生活、学习、陪伴和创造？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第三本，身体账。</strong> 不是问今天能不能扛，而是问：如果把现在的这种工作方式复制三年、五年，我的身体还能承受吗？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第四本，能力增值账。</strong> 三年以后，我会变得更有市场价值，还是只是越来越熟练地重复今天已经会做的事情？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第五本，自主度账。</strong> 我究竟拥有多少真正的控制权？不仅是几点上班、几点下班，还包括能不能安排自己的工作节奏、决定下一步想发展的能力，以及把最重要的时间投向哪里。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">第六本，关系与机会账。</strong> 这些年建立起来的人脉、声誉和机会，离开现在的平台之后，还有多少真正属于我？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这六本账里，最容易漏算的往往不是收入，而是那些不会直接写在工资条上的成本，以及那些不会立刻兑现的长期资产。</p>
<table width="100%" cellpadding="0" cellspacing="0" style="margin:36px 0 16px 0;"><tr><td width="4" style="background-color:#5BA88E;"></td><td style="background-color:#EBF7F3;padding:13px 18px;"><strong style="font-size:16px;color:#1A3D36;letter-spacing:1.5px;">三、一份工作最隐蔽的风险，是你越来越熟练，却不再成长</strong></td></tr></table>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我自己真正开始重新思考职业发展，并不是因为当时的工作特别辛苦。相反，那是一份外人看来几乎挑不出什么毛病的「好工作」：收入、平台、稳定性，都不错。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">最先亮红灯的反而是：<strong style="color:#1A3D36;">能力增值。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">在大型组织里，岗位往往被切割成一个个细小的格子。每个人会越来越熟悉自己的那一小块业务，越来越高效，越来越专业。但「越来越熟练」和「越来越有竞争力」，并不是一回事。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我曾经很明显地感觉到，工作在不断强化我已经会的东西，而我真正想继续发展的表达、创造、跨文化沟通等能力，却很少能在日常工作中派上用场。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">后来，我甚至需要自己到工作之外去寻找训练这些能力的机会。那时候我第一次认真问自己：</p>
<p style="font-size:16px;color:#1A3D36;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;font-weight:bold;text-align:justify;">如果一个职位长期只能调用我身上很窄的一部分能力，我究竟是在成长，还是只是越来越适应这个格子？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这也是我后来越来越警惕的一种职业状态：</p>
<p style="font-size:16px;color:#1A3D36;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;font-weight:bold;text-align:justify;">一份工作最隐蔽的风险，不是它让你做不好，而是它让你越来越擅长一件你已经不想再做十年的事情。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">能力增长一旦长期停滞，影响的不只是未来的竞争力，它还会慢慢反映到一个人对工作的整体满意度上。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">有一段时间，我的工作强度并不算高，也没有频繁加班，但精力却明显变差。后来我才慢慢意识到：<strong style="color:#1A3D36;">消耗精力的并不只有工作量。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">长期做一件已经很少给自己带来成长和意义感的事情，也会耗掉一个人的生命力。所以，职业倦怠感，未必只是因为工作太多；有时候，是手上的工作已经很久没有再把自己往前带了。</p>
<table width="100%" cellpadding="0" cellspacing="0" style="margin:36px 0 16px 0;"><tr><td width="4" style="background-color:#5BA88E;"></td><td style="background-color:#EBF7F3;padding:13px 18px;"><strong style="font-size:16px;color:#1A3D36;letter-spacing:1.5px;">四、机会很多，不等于选择权更多</strong></td></tr></table>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">工作多年以后，还有一个很容易产生的错觉：<strong style="color:#1A3D36;">市场上还有不少机会找上门，所以我的选择很多。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我自己也有过类似的经历。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">猎头找上门来的机会不少：更高一点的Title，更高一些的薪资，换一家同类公司。可真正问到工作内容，才发现很多只是「换汤不换药」。这就好像面前有很多扇门，推开以后，却发现后面仍然是同一个房间。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">对我而言，真正的选择权，是当环境或者自己的需求发生变化时，面前仍然有不止一条可行的路。无论是换一种工作方式，换职能，换行业，甚至换市场，过去积累的能力依然能够被重新组合、重新定价。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">最近和一位认识多年的朋友聊到职业变化。她也认真看过其他工作机会，但真正开始往外看时才发现：稳定工作多年以后，过去积累的一部分能力已经很久没有被外部市场重新验证。等到想换行业、换地区时，选择并不像原先想象的那么多。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这种「折旧」之所以隐蔽，是因为工资每个月照常到账，职位也没有消失，所以你很难察觉自己的外部竞争力可能正在一点点下降。直到真正想动的时候，才发现选择空间已经在不知不觉中收窄了。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">对我来说，职业安全感从来不是<strong style="color:#1A3D36;">「这份工作不会丢」</strong>，而是<strong style="color:#1A3D36;">「即使有一天它没有了，我依然有别的路可以走。」</strong> 说到底，稳定的不是一个职位，是我这个人——<strong style="color:#1A3D36;">我有能力走，只是今天选择留下。</strong></p>

<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">在职业研究中，有一个与这套判断密切相关的概念：<strong style="color:#1A3D36;">职业可持续性（career sustainability）</strong>。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">相关研究关注的也不只是一个人的收入和职位，还包括健康、满意度，以及能否持续创造价值和保持市场竞争力。收入当然属于其中的一部分，但绝不是全部。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">所以，算完这六本账以后，答案并不一定是辞职、转型、创业或者换国家。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">有时候算完以后，你得到的答案可能恰恰是：现在这份工作仍然值得留下。只是你需要开始学习一项新的能力，重新建立外部关系，或者主动给下一阶段多留一条路。</p>
<p style="font-size:16px;color:#1A3D36;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;font-weight:bold;text-align:justify;">真正危险的不是留下，而是从来没有重新计算过，却因为惯性一直留下。</p>

<p style="font-size:14px;color:#7BADA6;font-weight:bold;text-align:center;letter-spacing:2px;margin:0 0 20px 0;">写在最后</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">很多人第一次认真盘点自己的职业，往往是在裁员以后、健康出了问题以后，或者突然发现原来的路走不通以后。可如果今天40岁的人，职业生涯前方可能还有二三十年，我们其实没必要非等到撞墙，才第一次停下来问自己：这几年，我真正积累了什么？哪些能力正在升值？哪些能力已经开始折旧？现在的工作方式，我还能持续多久？如果保持现状再过三年，我的选择会更多，还是更少？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我认为，35岁以后，每隔一两年，或者每遇到一次重要的职业节点，都值得给自己的职业重新算一遍这笔账。不是因为人到中年就应该焦虑。恰恰是因为：<strong style="color:#1A3D36;">前面的路还很长。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">年轻的时候，我们更习惯问：这份工作能让我多赚多少？能不能再升一级？能不能去一个更大的平台？这些问题都没有错。只是到了35岁以后，也许还应该再多问一句：<strong style="color:#1A3D36;">为了得到这些，我正在拿什么交换？</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">真正好的职业选择，不只是让今天的你得到更多，也要让几年以后的自己，<strong style="color:#1A3D36;">依然有能力选择下一步。</strong></p>
