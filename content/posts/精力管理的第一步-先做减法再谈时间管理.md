<!-- ══ 正文开篇 ══ -->
<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">记得在加拿大金融行业工作的那段时间，有一个画面让我印象极深。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">下午两点半，Excel还开着，眼皮已经开始上下打架。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">不是因为熬夜——前一晚十一点就睡了。不是因为工作强度高——那天没有deadline，连会议都不多。但就是困。不是「有点乏」的那种困，是身子坐着却开始前后晃动的困，是眼皮像被强力胶粘住、每隔几分钟要靠意志力撑开的困。我的注意力像松掉的橡皮筋，明明在看屏幕，思绪却已经飘到窗外去了。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">最想做一件事：来一杯咖啡。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">但我知道不能喝。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">已经试过太多次了——我只要下午两点半以后喝了咖啡或茶，当晚必定睡不好，半夜会醒，第二天更困。只能硬撑，然后起身绕着楼层走两圈，把下午勉强撑过去。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">五点准时下班回家。计划吃完饭听网课。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">结果是：随便吃了两口，躺到床上「歇一下」。再睁开眼已经十一点了。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">一整个晚上，就这样没了。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">你有没有过类似的感觉？不一定是在金融行业，不一定是在做什么烧脑的活儿——但那种「明明没怎么忙，怎么还是这么累」的困惑，应该很多人都遇见过。每天的待办清单（to-do list）很长，到临睡前却发现最重要的事还没动；不是没时间做想做的事，是没有精力去做。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; font-weight: bold; text-align: justify;">如果你也经常经历这种「明明没生病，却总觉得转不动」的状态，那我们可能得了同一个症状——我把它叫做「中年精力紊乱症」。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 24px 0; text-align: justify;">这不是医学判断，这是一个描述。不管你是35岁还是45岁，只要身体开始跟不上头脑，整个人没病却转不动，这个词大概就适合你。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">有一个事实，让我第一次看到时感到一种莫名的宽慰。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">研究发现，很多人午后会自然地出现一个警觉性低谷，也就是我们常说的「post-lunch dip」。在这个时间段，人的注意力可能下降，反应变慢，困意也会增加。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">有意思的是，这种低谷并不完全是午饭造成的——即使没有吃午饭，也可能发生。而且，前一晚睡得好不好，以及当天的工作状态，都会影响这种低谷的强度。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">所以，下午两三点开始犯困，并不一定意味着你的意志力不够，而可能只是你身体的警觉性刚好进入了一个相对低谷。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 24px 0; text-align: justify;">但我们面对它的惯性反应几乎都是：喝咖啡，或者硬撑。短期也许有效，可长期的代价是精力账户透支越来越快，每天像一台越来越难充满的手机。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">知道了原因，接下来的问题是：那该怎么办？大多数人的答案是去学时间管理。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">我也这样想过。番茄工作法、四象限法则、早起一小时——一套一套都试过，每次学完都兴致勃勃，觉得找到了答案。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">但学了一段时间，我发现一个奇怪的规律：<strong style="color: #1A3D36;">越认真执行时间管理，能做的事越来越多，精力却越来越差。</strong></p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">原因后来想清楚了。很多时间管理方法有一个共同的逻辑倾向：它们默认「你的问题是时间不够」，于是不断地优化安排、压缩你的空档，以提高单位时间的产出。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">但如果你真正的问题不是时间不够，而是精力不对呢？</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">一天只有86400秒，管理得再好，也不会多出一秒。往已经透支的精力里塞更多任务，就像往一个漏桶里不停加水——不解决根本问题，只会漏得更快。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; font-weight: bold; text-align: justify;">时间是花出去的，花了就没了；精力是可以投资的，投对了有回报，投错了连本金都要亏。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">我们花了太多力气管那个没办法增加的东西（时间），却忽略了一个可以被主动经营的东西（精力）。</p>

<!-- ══ 引用块（Seneca）══ -->
<p style="text-align: center; color: #7BADA6; font-size: 14px; font-style: italic; line-height: 1.9; margin: 20px 0; letter-spacing: 0.5px;">
  "Time is invisible, so it's easy to spend. Most of us realize the value of time only near the end of our life."<br>
  ——Seneca
</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 24px 0; text-align: justify;">但比时间更隐形的，是精力。你看不见它在流失，等你意识到的时候，一整个晚上已经在困倦中消失了。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">精力不是「加」出来的，是「减」出来的。入口就两个动作。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 10px 0; font-weight: bold;">减法一：建一份「减法清单」（Don't Do List）</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">大多数人有待办清单（to-do list），但很少有人有它的反面——<strong style="color: #1A3D36;">减法清单</strong>（Don't Do List）：那些你决定不再做的事。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 10px 0;">做法只有三步：</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 6px 0; padding-left: 20px;">1. 把你现在正在做的所有的事列出来。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 6px 0; padding-left: 20px;">2. 逐一问三个问题：这件事推动我走向我真正想去的方向吗？它对我的成长有实质性的帮助吗？三个月后如果没做这件事，会有实质性的损失吗？</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; padding-left: 20px;">3. 三个问题中有两个答案是「不」，这件事就可以砍掉，或者交给别人。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">我当时从自己的清单里删掉了：午休刷资讯（美其名曰了解时事，刷完什么都没记住）；三个跟核心工作关联不大的例行会议（在场没有意义，不在场也没人问）；还有一个碍于面子接下来的副项目。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">砍完之后每周多出将近三小时。天没有塌，有的只是一种久违的轻盈感。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 20px 0; font-weight: bold; text-align: justify;">砍掉的那些事，没有一件真正重要。它们只是让你显得很忙，没有让你更进一步。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 10px 0; font-weight: bold;">减法二：每天只锁定「最重要的一件事」</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">但砍完之后，剩下的事情可能仍然还有很多。这时候需要第二个动作：每天只问自己一个问题——</p>

<p style="font-size: 16px; color: #3D6B63; line-height: 1.85; letter-spacing: 1px; margin: 16px 0; text-align: center; font-style: italic;">明天完成了哪件事，我会觉得这一天真的没有白过？</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0;">就一件，不是三件，就只有一件。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">这个方向，和 Gary Keller 在《The ONE Thing》中提出的一个核心问题很接近：</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;"><strong style="color: #1A3D36;">「此刻，有哪一件事，做了之后，其它事情都会变得更容易，甚至不再必要？」</strong></p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">把它写下来，放在第二天最显眼的地方，在你个人精力最好的时段优先完成它。其它的事，都往后排。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 0 0 24px 0; font-weight: bold; text-align: justify;">当我们定义清楚什么最重要，精力才会自然地流向真正值得的地方。</p>

<p style="text-align: center; font-size: 14px; font-weight: bold; color: #7BADA6; margin: 0 0 18px 0; letter-spacing: 3px;">写在最后</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">精力，不只是一个健康问题，更是一个管理问题。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">它是所有计划、目标和梦想的底层基础。精力垮了，头脑混沌，什么都是空谈。精力管好了，同样的24小时，你能做到的事会超出自己的想象。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 14px 0; text-align: justify;">这是精力管理系列的第一篇，我们先把根扎好。在这个系列里，我还会分别聊精力的三大支柱——运动、饮食、睡眠——不是泛泛的养生建议，而是在忙碌生活里真正可以落地的实操方案。</p>

<p style="font-size: 16px; color: #1A3D36; line-height: 1.85; letter-spacing: 1px; margin: 18px 0 14px 0; font-weight: bold; text-align: justify;">写下你的减法清单（Don't Do List）。找一件你一直在做、但你其实知道它不重要的事，从今天起21天不做它。很可能你会发现——它不在，天也不会塌。</p>

<p style="font-size: 16px; color: #2A3530; line-height: 1.85; letter-spacing: 1px; margin: 0 0 26px 0;">你的减法清单上，第一个要砍掉的是什么？</p>
