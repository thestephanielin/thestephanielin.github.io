<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">"今天讲课用的整套PPT，我几乎一个手指头都没动，全部交给AI做完了。"</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">前不久，我在吉隆坡参加一场AI workshop。主讲人对着台下几百名听众，非常兴奋地说出这句话。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">但那套几乎完全由AI生成的PPT，每一页都塞得很满，字体也很小。开场没多久，就有人从后排起身，换到了会场前排。表面上看，内容的确是"做出来"了，可如果这是一个面向几百人的专业培训，我很难说它已经"做好"了。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这件小事，让我开始认真思考一个问题：</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">当AI已经可以替我们写、研究、设计、做PPT、搭网站，甚至完成越来越多过去需要一个小团队才能完成的工作之后，人应该继续积累的，到底是什么？</strong></p>

<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">AI正在改变一个人做生意的门槛。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">Nasdaq Economic Institute今年6月分析美国企业申请数据时发现，从2025年初开始，新企业申请的增长越来越集中在solo entrepreneurs、freelancers和side-hustlers这类一人型业务。研究者认为，其中一个重要原因，是低成本的生成式AI和agent工具，让过去需要额外人手完成的网站、内容、客户沟通等工作，现在一个人也有机会承担。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">但这并不意味着未来属于"最会用AI的人"。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">一位给企业做AI培训的朋友，和我分享过一个有意思的观察：很多企业老板并没有技术背景，也不懂所谓的大模型原理。但他们开始上手以后，往往很快就能把AI用起来。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">因为支撑业务的那些底层积累，他们早就已经有了。他们知道哪个问题值得先解决，知道客户卡在哪里，知道自己的业务流程怎么跑，知道公司过去积累了哪些数据，也知道什么样的结果交付出去才算合格。AI只是后来加上去的一层工具。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">所以，未来我们要面对的并不是"人还是AI"（Human vs AI）的二选一，而是人和AI的协同（Human × AI）。AI更像一个乘数，它最后能把什么放大，仍然取决于前面那个"1"到底是什么。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">AI的确可以接手工作中一部分结构化的任务，帮助我们提高效率。只是当执行能力变得容易获得时，它本身就很难再成为溢价来源。<strong style="color:#1A3D36;">这也带来一个更现实的问题：当大家都越来越容易把东西"做出来"，客户为什么最后还要选择你？</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">答案或许就在执行的两端。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">一端是：<strong style="color:#1A3D36;">你知不知道什么值得做，以及什么才算做好。</strong>另一端是：<strong style="color:#1A3D36;">你能不能让需要你的人看见你，并且相信你的判断。</strong></p>

<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我自己使用AI越多，越能体会到个人判断力的重要性。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我曾经用一个AI agent处理一个很复杂的现实问题。我把情况告诉它，它很快给了我方案A、B、C。我告诉它A为什么行不通，它马上换了方案D。我又补充了现实中的另一个限制：D也不成立，于是它继续往下找。几轮下来，它终于被我"逼到绝境"，甩出一句：你的情况比我想象的要复杂得多，而且你掌握的背景信息比我多得多，我已经没有什么新的办法了。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这句话听着好笑，却恰好点到了问题的关键。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">AI非常擅长快速生成备选方案（options），可难的是：<strong style="color:#1A3D36;">哪个方案在现实世界里根本不成立？</strong>而这个答案，往往藏在搜索不到的细节里。比如一个行业里长期形成的潜规则，一个客户内部真正的决策方式，一个项目过去踩过的坑，一个市场表面数据背后的例外，甚至一段从来没有被写进文件里的历史。这些，都是具体情境（context）的一部分。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">所谓"十几年经验"，价值也未必在于你只是比别人多工作了十几年，而在于：<strong style="color:#1A3D36;">你是不是因此更早知道什么不该做，更快发现哪里有问题，也更清楚什么值得继续。</strong>这才是经验最后沉淀成的判断（judgment）。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">Microsoft在2026 Work Trend Index里也问过AI用户：随着AI承担越来越多的工作，人的哪些能力反而更重要？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">排在前两位的是：<strong style="color:#1A3D36;">AI输出的质量控制，50%；critical thinking，46%。</strong>近九成的受访者说，他们把AI输出当作起点，而不是终点，最终的判断仍然要由自己来做。微软在报告中还把更成熟的AI使用方式概括为：设定意图（intent）和质量标准（quality bar），运用判断（judgment）与辨别力（taste），并且为结果负责。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这里的taste，不只是我们通常说的"审美好不好"，它更像是一种通过长期经验训练出来的辨别力：<strong style="color:#1A3D36;">什么程度只是完成，什么程度才叫合格；什么东西虽然看起来不错，却不适合这个客户、这个场合和这个目的。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">再回到开头那份AI生成的PPT。AI执行得很快，关键在于生成文件之后，有没有人能够看着它说："不行。这页字太小，这个信息密度不适合几百人的阶梯教室，这个页面还没有达到专业演示（professional presentation）的标准，重新来。"这就是质量把关（quality control），也是taste。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">AI可以很快给你一个答案，却不能替你决定：<strong style="color:#1A3D36;">这个答案到底配不配得上你的名字。</strong></p>

<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">但即使上游的判断都做对了，也不等于生意就会自然发生。一个人做生意，还要跨过另外两道门。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">第一道门是：<strong style="color:#1A3D36;">触达。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">你很专业，不等于客户知道；你判断得很准，也要有能力把它翻译成客户听得懂、也愿意采取行动的语言。所以这里的"触达"，不只是发内容、做营销（marketing），<strong style="color:#1A3D36;">还包括沟通能力，以及你过去积累的行业关系、合作伙伴、转介绍（referrals）、专业社群和自己的内容渠道。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">专业能力只有抵达需求，才开始变成商业价值。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">第二道门是：<strong style="color:#1A3D36;">信任。</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">过去，一个做得很漂亮的网站、一份专业的proposal、一套完整的presentation，本身都可以释放某种信号：这个人看起来很专业。但当这些内容越来越容易被AI生成以后，它们用来证明"我很专业"的作用，也可能慢慢变弱。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">客户就会转而看其他证据：你真的做过吗？你真的理解我的问题吗？你的判断以前有没有经过现实检验？有没有人愿意推荐你？如果判断错了，你愿不愿意为结果负责？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">我自己的创业经验让我明白：有产品，不等于就有人愿意买；信任需要提前积累。AI的出现，又把这个问题往前推了一层。以后可能连"我能做出一个看起来很专业的交付物"，都越来越不足以证明你是谁。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">真正难以复制的，还是经过时间沉淀下来的东西：经验、判断、关系、口碑，以及由这些一点点积累起来的信任。</p>

<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">到了35+，很多成熟职场人已经习惯用工作年限来定义自己：十五年采购经验、二十年销售经验、十年管理经验等等。但年限本身不是资产。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">如果有一天，拿掉你名字后面的公司logo，拿掉职位、团队和预算，再加上AI把一部分你过去的执行能力也拉平之后，你还能带走什么？</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这时候，可以思考和盘点几个问题：<strong style="color:#1A3D36;">我是否比过去更能判断，什么问题值得解决？我是否理解某一类客户和某一个行业的实际情况？我是否知道，哪些结果只是"看起来完成"，哪些已经达到专业标准？</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">我能不能把自己的判断传递到真正需要它的人面前？有没有人因为我过去做过的事、取得的结果，愿意相信我的判断？</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">如果这些积累都还在，它们就不只属于上一份工作，也逐渐变成了属于你的个人资产。</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这并不是说，35岁以后每个人都应该去做一人公司。但一人公司提供了一个很残酷、也很诚实的测试：</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;"><strong style="color:#1A3D36;">当没有公司替你背书，也没有职位替你定价时，市场究竟愿意为什么样的你付钱？</strong></p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">这个问题，也许比"我还要再学几个AI工具"更值得花时间想清楚。</p>

<p style="font-size:14px;color:#7BADA6;font-weight:bold;text-align:center;letter-spacing:2px;margin:0 0 20px 0;">写在最后</p>
<p style="font-size:16px;color:#2A3530;line-height:1.85;letter-spacing:1px;margin:0 0 14px 0;text-align:justify;">AI越强，我们越没有必要和机器比赛谁做得更快。接下来更该花时间积累的，是判断、标准、关系和信任。工具会换，模型会换，但这些积累不会随之清零，而会跟着你的经验一起沉淀，在下一份工作、下一次转型，甚至下一次自己做生意时继续发挥作用。</p>
